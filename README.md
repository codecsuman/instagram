# Insta App (MERN Stack)

A full-stack Instagram-like web application built using the MERN stack with authentication, posts, chat, and media uploads.

---

## 🚀 Tech Stack

### Frontend
- React (Vite)
- Redux Toolkit
- Axios
- Tailwind CSS
- Radix UI

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT & Cookies
- Cloudinary (for image upload)
- Socket.io (Chat)

---

## ✅ Features

- User Authentication (Login / Register)
- Profile Management
- Create, Like & Comment on Posts
- Real-time Chat
- Image Upload with Cloudinary
- Protected Routes
- Auto logout on token expiry
- Responsive UI
